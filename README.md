## 📌 Project Overview

The **Fitness Tracker System Management** is a MySQL-based relational database project designed to manage and analyze users' fitness activities, health metrics, subscriptions, payments, and rewards.

The project demonstrates advanced SQL concepts such as **database normalization, triggers, stored procedures, views, joins, event scheduler, and database automation** to build an intelligent fitness management system.
